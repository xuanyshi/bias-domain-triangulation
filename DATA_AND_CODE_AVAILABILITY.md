# Data and code availability

The data supporting the current DAG132 analysis are provided in the article, its Supplementary Information, and the [`analysis/`](analysis/) directory of this repository. The inventory contains 39 estimates from 24 articles; the primary analysis retains 38 estimates from 23 articles. All study-level data were extracted from published reports. No individual-level participant data were used.

The repository provides the adopted DAG, adjustment sets, construct-coverage rules, model ratings, analysis inputs, numerical figure data, and scripts for the primary meta-analysis, sensitivity analyses and descriptive population–family model comparison. Model ratings and supplementary Tables S2 and S10 are available in [`analysis/supplementary_tables/`](analysis/supplementary_tables/).

Run instructions and software requirements are provided in [`analysis/README.txt`](analysis/README.txt). The manuscript should cite the commit corresponding to the submitted analysis. The [tutorial](https://xuanyshi.github.io/bias-domain-triangulation/) describes application of the framework to other exposure–outcome questions.

The current edge-assessment protocol and model settings are documented in [`analysis/edge_protocol/`](analysis/edge_protocol/). Verbatim original-language edge-assessment records are retained separately by the authors. Previously released discovery prompts and outputs remain in [`prompts/`](prompts/) and [`llm_outputs/`](llm_outputs/); these directories have their own version scope.
